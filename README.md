# Responsive Dropdown Sidebar

This project is a modern, responsive sidebar navigation component built with HTML, CSS, and JavaScript. It features a collapsible sidebar with dropdown menus, smooth transitions, and a clean, professional design.

## Features

- **Responsive Design:** The sidebar adapts to different screen sizes and can be collapsed or expanded.
- **Dropdown Menus:** Navigation items can have sub-menus that expand on click.
- **Smooth Transitions:** CSS transitions provide a smooth user experience when toggling the sidebar or dropdowns.
- **Modern UI:** Uses the Noto Sans font and Boxicons for a clean, modern look.
- **Sticky Header:** Includes a header section that remains at the top of the page.

## Technologies Used

- HTML5
- CSS3 (Flexbox, transitions, custom scrollbar hiding)
- JavaScript (for sidebar and dropdown interactivity)
- [Boxicons](https://boxicons.com/) for icons
- [Google Fonts - Noto Sans](https://fonts.google.com/specimen/Noto+Sans)

## How It Works

- The sidebar is fixed to the left of the screen and contains navigation links.
- Clicking the menu icon in the header toggles the sidebar between expanded and collapsed states.
- Some navigation items have dropdown sub-menus that can be expanded or collapsed by clicking the arrow icon.
- The "Settings" and "Logout" options are positioned at the bottom of the sidebar for easy access.

## Usage

1. Clone or download this repository.
2. Open `index.html` in your browser to view the sidebar in action.
3. Customize the navigation links and sub-menus as needed for your project.

## File Structure

- `index.html` - Main HTML file containing the sidebar and header structure.
- `style.css` - Styles for the sidebar, header, and responsive layout.
- `script.js` - JavaScript for sidebar toggling and dropdown functionality.
